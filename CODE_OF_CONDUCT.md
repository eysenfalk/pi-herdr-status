# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Assume good intent while discussing code, behavior, and evidence rather than people. Harassment, discrimination, threats, doxxing, and deliberate disclosure of private prompts, credentials, or session data are not tolerated.

## Scope

This standard applies in repository issues, pull requests, discussions, and other project spaces.

## Enforcement

For ordinary conduct concerns, contact the maintainer privately through the address or private channel listed on their GitHub profile. For security-sensitive reports, use GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md). Maintainers may edit or remove content and restrict participation to protect contributors and users.

This concise policy is adapted from the principles of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

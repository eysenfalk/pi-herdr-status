# Support

## Something looks wrong

Open a bug report with the package, Pi, Herdr, Node.js, and operating-system versions; expected and observed state transitions; and the smallest content-free reproduction. State whether the issue survives `/reload` in a fresh Herdr-managed Pi session.

Never attach credentials, complete session files, prompts, transcripts, tool arguments, tool output, or raw socket traffic.

## Questions and ideas

Use the question or feature-request templates. Read [Architecture](docs/architecture.md) before proposing lifecycle changes.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

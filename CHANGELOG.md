## [1.0.0-rc.0]

### Added

- Native Pi prompt lifecycle bridging through Herdr's existing `herdr:blocked` event.
- Read-only local-socket reconciliation for confirmed stale lifecycle status.
- Bounded retry, 30-second heartbeat, cancellation, and foreign-blocker protection.
- Deterministic tests, packed-Pi smoke test, package and workflow contracts, and public project documentation.
